# Initial release plan

## v0.1.0-alpha

- Publish the dependency-free CLI, schemas, minimal example, and CI.
- Collect feedback on decision semantics and interoperability.
- Label schema-breaking changes clearly.

## v0.2.0

- Add JSON Schema validation at the CLI boundary.
- Add GitHub Check annotations and reusable workflow examples.
- Add signed evidence-manifest guidance.

## v1.0.0 criteria

- Stable state and gate schemas.
- Two independent example integrations.
- Documented migration policy and security review.
- At least one release candidate tested by an external maintainer.

No release is considered ready solely because CI is green; documentation, security, provenance, and independent review must also be complete.
